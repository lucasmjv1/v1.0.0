## 🚀 Sobre o Projeto

O **Monarch Social** é uma rede social desenvolvida para oferecer uma experiência fluida, moderna e sem distrações. Com foco em privacidade, liberdade e alta performance, a plataforma combina um visual futurista em tons de roxo neon e preto com recursos pensados para comunidades gamers e criadores de conteúdo.

#### Passo a passo para instalar:
1. Faça o download do arquivo `monarch.apk` clicando no botão acima.
2. Abra o arquivo no seu celular Android.
3. Se solicitado, ative a permissão para **"Instalar de fontes desconhecidas"**.
4. Conclua a instalação e abra o **Monarch Social**!
